# Orbitz Sticky Notes 0.2.0-beta.1

Orbitz Sticky Notes is ready for its first public beta. This release focuses on a more reliable daily workflow for desktop notes and code snippets.

## What's included

- Sticky Code uses the same note record as the regular note, so switching views preserves the title and content.
- Sticky Code resizes in both directions with long content through its own resize handle.
- Note positions, sizes, attachments, and content persist across a Flatpak update.
- Hidden and archived notes can be restored from their menus.
- Secret notes return to a locked state when hidden or reopened.
- Per-note opacity is available in both note and Sticky Code views.
- Image and PDF attachments include compact previews; email drafts include the note body and selected attachments.

## Compatibility

- Ubuntu 22.04 and Ubuntu 24.04, x86_64.
- Flatpak runtime: GNOME 49.
- GTK 3 over X11 or XWayland. Native Wayland-only sessions and ARM64 builds are not covered by this beta.

## Known limits

- Ubuntu 22.04 validation was limited to clean installation, upgrade, persistence, and headless startup. Interactive behavior was checked on Ubuntu 24.04/GNOME 46 only.
- Thunderbird opened its first-run account setup instead of the compose editor in the disposable VM. The app's email handoff was invoked, but the actual composer contents and attachment were not visually verified. Automated tests verify MIME draft creation with a synthetic body and attachment. No message was sent.
- Not every menu command was individually activated in the final build; see the QA report for the checked flows and remaining coverage.
- Window placement, portals, accessibility, and always-on-top behavior can vary across desktops and compositors.
- PIN locking hides note content in the interface; it does not encrypt the SQLite database or backups.
- No automatic update channel or Flathub listing is provided.

## Install

Download `orbitz-sticky-notes-x86_64.flatpak` and `SHA256SUMS` from the GitHub release, verify the checksum, then install:

```sh
sha256sum -c SHA256SUMS
flatpak install --user ./orbitz-sticky-notes-x86_64.flatpak
flatpak run io.orbitz.Postits
```

Your existing Flatpak data is preserved when updating from 0.1.0.
