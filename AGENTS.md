# Repository guidance

## Project boundary

This repository is the standalone **Orbitz Sticky Notes** project. Its Codex project root is this repository, separate from `orbitz-widgets-for-gnome`; do not edit, install, or document Widgets as part of Sticky Notes work unless the user explicitly requests cross-project integration. Treat Sticky Notes as an independent application, release, and issue backlog.

Preserve the current working tree, including release QA evidence and existing user changes. Never replace or discard them while setting up project context. Keep Sticky Notes product documentation and validation evidence in this repository.

When creating or revising the public README, follow [`docs/readme-style-guide.md`](docs/readme-style-guide.md). Preserve its user-focused structure, English language, polished community-facing tone, and explicit treatment of privacy, compatibility, and product limits.
